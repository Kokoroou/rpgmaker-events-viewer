RPG Maker event viewer FAQ

MakerLens Events shows the events of an RPG Maker game (2000, 2003, XP, VX, VX Ace, MV or MZ) as a flow graph, right in your browser: dialogue, choices, conditions, labels and jumps, and it plays dialogue scenes. It works on released games, with no editor and no plugin. Your files never leave your device.

How to use

  1. Open a game. Press Select Game Folder and pick the game's main folder (the one next to Game.exe) or its data/ folder, or drop it on the page.
  2. Pick a map, then an event. Maps are in the sidebar, in the editor's order; the event's commands appear as a flow graph.
  3. Read a node. Click it to see its full text in the inspector. Events with several pages have page tabs above the graph.
  4. Find things. Type in the sidebar's search box (or press /) to find scenes and events by name. Common events are listed under the maps.
  5. Play a scene. Scenes (pictures with dialogue) are listed first in the sidebar: press Preview to play one like in the game.

Opening a game

How do I view the events of an RPG Maker game?

Open a game folder, then pick a map and an event.

  1. Open MakerLens Events, press Select Game Folder and pick the game's folder, or drop the folder anywhere on the page.
  2. Pick a map in the sidebar, then an event. Its commands appear as a flow graph.
  3. Click a node to read its full text in the side panel.
  4. Events with more than one page have page tabs.

Which folder do I select?

The game's root folder, or its data/ folder on its own.

  • MV games keep it in www/data/, MZ games in data/. MakerLens Events finds either.
  • It reads MapInfos.json (the map tree), every Map###.json, CommonEvents.json, System.json (switch and variable names) and Actors.json.
  • Images and audio are not needed.

Do I need the RPG Maker editor, the project file or a plugin?

No. It reads a released game as it is shipped.

  • You do not need to own RPG Maker, open the project or start a playtest.
  • Node editors and debugger plugins run inside the game or the editor; this does not.
  • Nothing is installed into the game, and the game is never changed.

Which RPG Maker versions are supported?

RPG Maker 2000 / 2003, XP, VX, VX Ace, MV and MZ.

  • 2000 / 2003 keep events in RPG_RT.ldb, RPG_RT.lmt and Map####.lmu in the game folder itself. Their Japanese (Shift-JIS) or Western text is recognised, and scene previews take pictures from Picture/ and sound from Music/ and Sound/.
  • XP, VX and VX Ace keep them in Ruby files (.rxdata, .rvdata, .rvdata2), usually packed in .rgssad, .rgss2a or Game.rgss3a. Open the game folder and they are read from the archive in your browser.
  • MV and MZ keep them in plain JSON.
  • For the images and audio of every version, use MakerLens Assets.

Can I open a game from an archive or a link?

Yes, with View another way on the start screen. It offers three options.

  • Archive: Game.rgss3a, .rgss2a or .rgssad, picked on its own.
  • Game link: it comes from the game itself (⚙ → Share → MakerLens link). Its token sits after the #, so no server receives it. Only https://*.workers.dev addresses are accepted.
  • Data files: picked one by one.

Why does it say “No RPG Maker game data found”?

It found no data/ folder and no Map###.json file in what you selected.

  • Select the game's root folder (the one with Game.exe) or its data/ folder, not img/ or audio/.
  • Some released games pack all their files into the .exe or encrypt data/ with a plugin. MakerLens Events cannot read those.

Reading the graph

What does the flow graph show?

Five kinds of node.

  • Dialogue: Show Text, with the speaker name in MZ.
  • Choices: Show Choices, one branch per option.
  • Conditions: Conditional Branch, with its Else branch.
  • Labels.
  • Jumps to a label, drawn as dashed arrows.
  • Not drawn yet: other commands, such as Control Switches, Transfer Player, a Common Event call or a script.

How do I find what unlocks an ending or a hidden route?

Follow the condition nodes from the event that starts the ending.

  1. Open the event that starts the ending.
  2. Follow its condition nodes. Each one names the switch, variable or actor it tests, such as If [Switch: Met the witch].
  3. Look for the event that leads into that branch.

The conditions on an event page's own settings (the editor's page conditions) are not shown yet. Switch between the page tabs to compare pages.

Are switch, variable and actor names shown?

Yes. Names come from the game's System.json and Actors.json.

  • A condition reads If [Variable: Gold found] rather than a bare number.
  • In dialogue, the \N[n] and \V[n] text codes are replaced with the actor name and the variable name.
  • A switch without a name shows its number instead, such as If [Switch #12].

Can I see common events?

Yes. Common events are listed below the maps in the sidebar.

  • They open as graphs the same way.
  • Maps keep the tree and folder order of the editor, from MapInfos.json.

Can I play a scene with its pictures and sound?

Yes. Press Preview on a scene.

Find a scene

  • Scenes are common events and event pages that show pictures together with dialogue. They are listed under Scenes at the top of the sidebar.
  • The Preview button is on the scene's card in the event list, or in the toolbar once the graph is open.

What you see

  • The player dims the page and shows the scene at the game's screen size, line by line.
  • Pictures, picture animations, face graphics, music and sound effects play with it.
  • Messages type themselves out at 300 words a minute. Click while a line is typing to show it whole.
  • Choices are offered as buttons.
  • When a picture depends on the hero's state, such as the outfit they wear, the player shows the game's starting state.

Controls

  • Click or press → to continue; ← to go back.
  • A turns on auto play, which leaves each line on screen for two more seconds once it is shown in full.
  • H or the eye button hides the dialogue so you can see the pictures; a click brings it back.
  • At the end of a scene the next one in the Scenes list follows on, and going back from the first line opens the previous one. Shift+→ and Shift+← skip a whole scene.

Good to know

  • Open the game's root folder (not data/) so the pictures and audio can be found.
  • Encrypted files are decrypted in memory, never saved or uploaded.
  • Simple scripts that show or erase pictures or set variables are followed. Other effects made by plugins or scripts are not played.

Can a scene follow my own save file?

Yes, with Use a save in the toolbar.

  1. Press Use a save.
  2. Pick a save of the open game:
    • MV: www/save/file1.rpgsave
    • MZ: save/file1.rmmzsave
    • VX Ace: Save01.rvdata2
    • VX: Save1.rvdata
    • XP: Save1.rxdata
  • Scenes then start from that save's switches, variables, self switches, actor names and equipment, and party, so a condition takes the branch your game would take instead of a guess.
  • The save is only read, in your browser. It is never changed or uploaded.
  • It is dropped when you press the button again or open another game.

Which branch does a line of dialogue belong to?

Follow the arrows back up from the line's dialogue node.

  1. Find the line's dialogue node.
  2. Follow the arrows back up. The choice option or the If / Else branch above it is the branch.
  3. Click any node to read the full text in the side panel.

This is handy for translators who need to know when a line is said.

Privacy, editing and legal

Can I edit events or export them?

No. MakerLens Events is read-only.

  • It never writes to the game files and has no export.
  • To change events, use the RPG Maker editor.

Are my game files uploaded anywhere?

No. Your files never leave your device.

  • Files are read by your browser and stay on your device.
  • The page's Content-Security-Policy blocks requests to any server except these two.
  • An anonymous counter, which receives only the page address, the referrer and the names of a few actions (such as how a game was opened or which feature was used, never what was opened).
  • The optional feedback form, which sends only the rating and comment you choose to send.

Details: Privacy & analytics.

Do I need to install anything? Does it work offline?

No. It needs no installation and no account.

  • It works best in Chrome or Edge. Firefox works too, through its folder picker.
  • All libraries are served from this site, so once the page has loaded it works without an internet connection.
  • The source code is on GitHub (MIT license).

Is it legal to look at a game's events?

MakerLens Events only reads files that are already on your computer and changes nothing.

  • It is meant for your own games, or games you have permission to study, for example to write a guide or a translation.
  • Reusing a game's story or text elsewhere may need the rights holder's permission.
  • Check the game's terms.

Can I move to MakerLens Assets without picking the folder again?

Yes, in Chrome or Edge.

  • Once a game folder or game link is open, the Assets | Events switch in the header opens the same game in MakerLens Assets.
  • The folder stays on your device and is handed over inside the browser.
  • Firefox, Safari and files picked one by one cannot hand a folder over.

How do I get a game's images and music?

Use MakerLens Assets, the other MakerLens tool.

  • It opens the same game folder.
  • It previews and downloads its encrypted images and audio (.rpgmvp, .png_, .ogg_ and more), also in your browser.
