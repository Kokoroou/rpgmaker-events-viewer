RPG Maker event viewer FAQ

MakerLens Events shows the events of an RPG Maker game (MV, MZ, VX Ace, VX, XP, 2000 or 2003) as a flow graph, right in your browser: dialogue, choices, conditions, labels and jumps, and it plays dialogue scenes. It works on released games, with no editor and no plugin. Your files never leave your device.

How to use

  1. Open a game. Press Select Game Folder and pick the game's main folder (the one next to Game.exe) or its data/ folder, or drop it on the page.
  2. Pick a map, then an event. Maps are in the sidebar, in the editor's order; the event's commands appear as a flow graph.
  3. Read a node. Click it to see its full text in the inspector. Events with several pages have page tabs above the graph.
  4. Find things. Type in the sidebar's search box (or press /) to find scenes and events by name. Common events are listed under the maps.
  5. Play a scene. Scenes (pictures with dialogue) are listed first in the sidebar: press Preview to play one like in the game.

Opening a game

How do I view the events of an RPG Maker game?

Open MakerLens Events, press Select Game Folder and pick the game's folder, or drop the folder anywhere on the page. Pick a map in the sidebar, then an event: its commands appear as a flow graph. Click a node to read its full text in the side panel, and use the page tabs for events with more than one page.

Which folder do I select?

The game's root folder works, and so does its data/ folder on its own. MV games keep it in www/data/, MZ games in data/; MakerLens Events finds either. It reads MapInfos.json (the map tree), every Map###.json, CommonEvents.json, System.json (switch and variable names) and Actors.json. Images and audio are not needed.

Do I need the RPG Maker editor, the project file or a plugin?

No. It reads a released game as it is shipped, so you don't need to own RPG Maker, open the project or start a playtest. That is the difference from node editors and debugger plugins, which run inside the game or the editor. Nothing is installed into the game, and the game is never changed.

Which RPG Maker versions are supported?

RPG Maker MZ, MV, VX Ace, VX, XP and 2000 / 2003. MV and MZ keep events in plain JSON; VX Ace, VX and XP keep them in Ruby files (.rvdata2, .rvdata, .rxdata), usually packed in Game.rgss3a, .rgss2a or .rgssad: open the game folder and they are read from the archive in your browser. RPG Maker 2000 / 2003 keep them in RPG_RT.ldb, RPG_RT.lmt and Map####.lmu in the game folder itself; their Japanese (Shift-JIS) or Western text is recognised, and scene previews take pictures from Picture/ and sound from Music/ and Sound/. For the images and audio of every version, use MakerLens Assets.

Why does it say “No RPG Maker game data found”?

It found no data/ folder and no Map###.json file in what you selected. Select the game's root folder (the one with Game.exe) or its data/ folder, not img/ or audio/. Some released games pack all their files into the .exe or encrypt data/ with a plugin; MakerLens Events cannot read those.

Reading the graph

What does the flow graph show?

Five kinds of node: dialogue (Show Text, with the speaker name in MZ), choices (Show Choices, one branch per option), conditions (Conditional Branch, with its Else branch), labels, and jumps to a label, drawn as dashed arrows. Other commands, such as Control Switches, Transfer Player, a Common Event call or a script, are not drawn yet.

How do I find what unlocks an ending or a hidden route?

Open the event that starts the ending and follow its condition nodes: each one names the switch, variable or actor it tests, such as If [Switch: Met the witch]. Then look for the event that leads into that branch. Note that the conditions on an event page's own settings (the editor's page conditions) are not shown yet; switch between the page tabs to compare pages.

Are switch, variable and actor names shown?

Yes. Names come from the game's System.json and Actors.json, so a condition reads If [Variable: Gold found] rather than a bare number. In dialogue, the \N[n] and \V[n] text codes are replaced with the actor name and the variable name. A switch without a name shows its number instead, such as If [Switch #12].

Can I see common events?

Yes. Common events are listed below the maps in the sidebar and open as graphs the same way. Maps keep the tree and folder order of the editor, from MapInfos.json.

Can I play a scene with its pictures and sound?

Yes. Scenes, the common events and event pages that show pictures together with dialogue, are listed under Scenes at the top of the sidebar; their Preview button (on the scene’s card in the event list, or in the toolbar once the graph is open) plays them on screen. The player dims the page and shows the scene at the game's screen size, line by line, with its pictures, picture animations, face graphics, music and sound effects. Messages type themselves out at a reading speed of 300 words a minute (click while a line is typing to show it whole); click or press → to continue, ← to go back, A for auto play, which leaves each line on screen for two more seconds once it is shown in full; choices are offered as buttons. At the end of a scene the next one in the Scenes list follows on, and going back from the first line opens the previous one (Shift+→ and Shift+← skip a whole scene). H or the eye button hides the dialogue so you can see the pictures; a click brings it back. When a picture depends on the hero's state, such as the outfit they wear, the player shows the game's starting state. Open the game's root folder (not data/) so the pictures and audio can be found: encrypted files are decrypted in memory, never saved or uploaded. Simple scripts that show or erase pictures or set variables are followed; other effects made by plugins or scripts are not played.

Can a scene follow my own save file?

Yes. Press Use a save in the toolbar and pick a save of the open game: www/save/file1.rpgsave (MV), save/file1.rmmzsave (MZ), Save01.rvdata2 (VX Ace), Save1.rvdata (VX) or Save1.rxdata (XP). Scenes then start from that save's switches, variables, self switches, actor names and equipment, and party, so a condition takes the branch your game would take instead of a guess. The save is only read, in your browser: it is never changed or uploaded, and it is dropped when you press the button again or open another game.

Which branch does a line of dialogue belong to?

Find the line's dialogue node and follow the arrows back up: the choice option or the If / Else branch above it is the branch. Click any node to read the full text in the side panel. This is handy for translators who need to know when a line is said.

Privacy, editing and legal

Can I edit events or export them?

No. MakerLens Events is read-only: it never writes to the game files and has no export. To change events, use the RPG Maker editor.

Are my game files uploaded anywhere?

No. Files are read by your browser and never leave your device. The page's Content-Security-Policy blocks requests to any server except an anonymous counter, which receives only the page address, the referrer and the names of a few actions (such as how a game was opened or which feature was used, never what was opened), and the optional feedback form, which sends only the rating and comment you choose to send. Details: Privacy & analytics.

Do I need to install anything? Does it work offline?

No installation and no account. It works best in Chrome or Edge; Firefox works too, through its folder picker. All libraries are served from this site, so once the page has loaded it works without an internet connection. The source code is on GitHub (MIT license).

Is it legal to look at a game's events?

MakerLens Events only reads files that are already on your computer and changes nothing. It is meant for your own games, or games you have permission to study, for example to write a guide or a translation. Reusing a game's story or text elsewhere may need the rights holder's permission, so check the game's terms.

How do I get a game's images and music?

Use MakerLens Assets, the other MakerLens tool. It opens the same game folder and previews and downloads its encrypted images and audio (.rpgmvp, .png_, .ogg_ and more), also in your browser.
